1. Get VIN (establish actual model) 

2. Find which Alternator was in this model

3. Find which 14V automotive voltage regulator for this alternator

## To determine which exact model you have, I'd use this hierarchy:

1. Chassis/model code — GD1/GD2/GD3/GD4.

2. Engine code — L13A vs L15A.

3. 2WD vs 4WD.

4. Transmission/trim.

Alternator part number — useful for confirming the production/component family, but not sufficient to identify the chassis.
