# 01. Vehicle Identification & Chassis Matrix

## Overview
Because this vehicle is a Right-Hand Drive (RHD) Japanese Domestic Market (JDM) import in the Caribbean, identifying the exact sub-model and production run is essential before ordering parts. In Japan, first-generation Fits began rolling off assembly lines in June 2001.

---

## 1. First-Generation Fit Chassis Matrix

| Model Code | Engine | Valvetrain | Drivetrain | Production Period | Cayman Island Prevalence |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **GD1** | **1.3L L13A** | **i-DSI (8 plugs)** | **2WD (FF)** | **June 2001 – Nov 2007** | **Primary target (90%+ of early imports)** |
| **GD2** | 1.3L L13A | i-DSI (8 plugs) | 4WD (Real-Time) | June 2001 – Nov 2007 | Rare (Japan snowy regions only) |
| **GD3** | 1.5L L15A | VTEC (4 plugs) | 2WD (FF) | Sept 2002 – Nov 2007 | Sport trim, introduced late 2002 |
| **GD4** | 1.5L L15A | VTEC (4 plugs) | 4WD (Real-Time) | Sept 2002 – Nov 2007 | Very rare |

> **Note on "2002" Dating:**  
> A vehicle registered as "2002" cannot be assumed to be a GD1 solely by year, though it is the most probable. The chassis tag provides the definitive proof.

## 2. Reading the Vehicle ID Plate

Look for the blue/silver aluminum tag riveted to the engine bay firewall or driver-side door aperture.

```text
+------------------------------------------+
| HONDA MOTOR CO., LTD. JAPAN              |
|                                          |
| MODEL     : LA-GD1                       |  <-- Confirms GD1 (1.3L 2WD)
| ENGINE    : L13A                         |  <-- Confirms 8-plug i-DSI
| FRAME NO. : GD1-105XXXX                  |  <-- Exact build sequence
| TRANS     : S5DA / CVT                   |
| COLOR     : NH623M (Satin Silver)        |
+------------------------------------------+
```

## 3. Mitsubishi Alternator OEM Connection

Factory documentation verifies that Honda contracted **Mitsubishi Electric** to build the OEM charging systems for the first-generation Fit:

- **Factory Descriptor:** `A.C. GENERATOR (MITSUBISHI)`
- **OEM Part:** `31100-PWA-004`
- **Mitsubishi Code:** `AHGA56` / `A5TB0091`

### Shared Component Genealogy
Honda standardized this unit across several contemporary models:
- **Fit / Jazz:** GD1 (1.3L) & early GD3 (1.5L)
- **Civic:** EU / ES 1.4L European/Asian markets
- **Mobilio / Spike:** GB1 / GK1
- **Airwave:** GJ1 (later supersessions)

Because the AHGA56 was shared between both the 1.3L (GD1) and 1.5L (GD3), **the alternator part number cannot be used in reverse to determine your engine size**, but it guarantees interchangeability between these donor vehicles in Cayman scrap yards.
